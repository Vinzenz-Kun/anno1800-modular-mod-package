# [Legacy] Aput's Lodge Portrait

I wanted players returning to an older Arctic settlement to recognise Aput in their Lodge again. You can use this portrait repair with the original Arctic Lodge Specialists, even if you skip every gameplay cheat in the collection.

This is one module in the Anno 1800 Modular Specialists Bundle. With the full collection enabled, even supplying a city and balancing its budget can become optional. Choose the changes you want for your save.

The patch recognises Aput, the Eternal Hearth (2001000104), and replaces the missing engineer icon with the game's Arctic Science Reporter portrait. Existing copies retain their item identity. The patch activates only if the original missing icon is still assigned.

## Installation

Copy `[Legacy] Lodge Portraits` into Anno 1800's `mods` folder alongside the original Arctic Lodge Specialists.
