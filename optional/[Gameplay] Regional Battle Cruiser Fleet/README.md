# [Gameplay] Regional Battle Cruiser Fleet

Start a new game with five battle cruisers, one outfitted for each destination. Like the other modules in this collection, this is a powerful optional shortcut. Install it when you want to spend the early game settling islands with your specialists already aboard.

Each cruiser is named for its destination and carries its construction materials in its initial inventory. Each cruiser starts with four ship specialists equipped: Dr Rowan Pike for expeditions, Captain Mara Voss for combat, Ellis Ward for cargo handling and Lord High Admiral Nadasky from the base game.

The eight cargo holds carry 50 t each of Timber, Bricks and Steel Beams, one regional production Jack, one regional needs specialist, both editions of Robin Vale and the fifth specialist listed below. Unload these five passengers at their destination. The Arctic receives the Lodge editions. The cruisers retain normal battle cruiser upkeep.

| Destination | Fifth specialist |
| --- | --- |
| Old World | Cargo Purser |
| Cape Trelawney | Harbour needs specialist |
| New World | Harbour production Jack |
| Arctic | Expedition specialist |
| Enbesa | Combat specialist |

Copy this folder and all 15 bundle specialist modules into your game's mods folder. Disable any older starting-fleet mod before starting a new game. In sandbox, all four starting-ship settings grant the five ships together in the starting session. Sail them to their intended regions as those regions unlock. In the campaign, the five cruisers arrive through the original fleet's early Old World quest event. They supplement the story ships. The module does not unlock DLC regions or grant ships retroactively after the event.

This design revisits the earlier personal Battle Cruiser Starting Fleet. Thank you to the modders whose specialists inspired the regional loadouts. Each specialist module credits its original influences.
